# PodcastFlow

Десктоп-приложение для ведения подкаста: эпизоды, медиаплан, файлы в Object Storage и настройки шоу. Стек: **Tauri 2**, **Vue 3**, **TypeScript**, **Tailwind CSS 4**, **Bun**.

## Возможности

- **Эпизоды** — список, форма создания/редактирования, конвертация аудио в MP3, превью плеера
- **Медиаплан** — календарь публикаций
- **Файлы** — просмотр и удаление объектов в Yandex Object Storage
- **Настройки** — метаданные подкаста, обложка, storage, git-репозиторий каталога, ссылки; импорт из Mave

Данные каталога хранятся в git-репозитории; аудио и обложки — в Yandex Object Storage.
